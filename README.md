# Puzzle Paws Memory Game

Paws Memory Game is a fun and interactive card-matching game where players uncover pairs of animal cards as quickly as possible. The game tracks moves and completion time, stores personal best records using localStorage, and features custom-designed welcome and success modals inspired by a playful pet-themed interface.

## Features

- Match pairs of animal cards
- Move counter and game timer
- Best score and fastest time tracking
- Player name persistence using localStorage
- Responsive design for desktop and mobile
- Restart and Play Again functionality
- Animated card flip effects
- Custom welcome and success modals

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## User Testing & Feedback

As part of the development process, Puzzle Paws was tested with young children to evaluate usability, engagement, and overall enjoyment. The goal was to observe whether first-time users could understand the gameplay without assistance and whether the interface was suitable for the target audience.

### Participants

- Child, 6 years old
- Child, 5.5 years old

### Results

Both participants immediately understood how to play the game without requiring instructions or guidance. The animal-themed illustrations generated a positive emotional response and encouraged repeated play.

The 6-year-old player became excited by the game mechanics and attempted to improve her score several times, replaying the game three to four times consecutively.

The 5.5-year-old participant repeatedly asked to play again and remained engaged through at least five consecutive rounds. During gameplay, both children laughed at the animal illustrations, celebrated successful matches with enthusiastic reactions such as "yay!", and appeared genuinely happy when completing the game and viewing their results.

These observations suggest that the game's core mechanics are intuitive and engaging for young children, and that the visual design successfully supports player enjoyment and motivation.

### Usability Observations

The testing sessions also revealed several opportunities for future improvements:

- Card illustrations could be displayed slightly larger on smaller mobile screens to improve visibility and interaction.
- The success modal could present statistics in a more child-friendly visual format, allowing younger users to recognize achievements without assistance from an adult.
- The Restart button was not immediately intuitive for young children because it relies solely on text. An icon-based button may improve discoverability and understanding.
- Touch interactions functioned correctly only when the game entered its responsive mobile layout. For this reason, mobile testing was conducted using the browser's device emulation tools.
