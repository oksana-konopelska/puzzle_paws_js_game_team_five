# Puzzle Paws Memory Game

Paws Memory Game is a fun and interactive card-matching game where players uncover pairs of animal cards as quickly as possible. The game tracks moves and completion time, stores personal best records using localStorage, and features custom-designed welcome and success modals inspired by a playful pet-themed interface.

## Features

- Match pairs of animal cards
- Move counter and game timer
- Best score and fastest time tracking
- Player name persistence using localStorage
- Responsive design for desktop and mobile
- Restart and Play Again functionality
- Animated card flip effects
- Custom welcome and success modals

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Getting Started

1. Clone the repository:
   ```bash
   git clone repository name
   ```

2. Navigate to the project folder:
   ```bash
   cd puzzle_paws_js_game_team_five
   ```

3. Open `index.html` in your browser.
